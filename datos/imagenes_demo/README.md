# Imágenes de demostración

Las seis imágenes son recortes de una lámina sintética generada para este proyecto con OpenAI. Se incluyen como material de demostración académica. Usa «Imágenes sintéticas del proyecto» como fuente y «Uso en la demostración académica» como condición de uso en el catálogo. Las imágenes 0 a 4 son las candidatas y la imagen 5 sirve para la consulta.
